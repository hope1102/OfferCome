Use the project's forest green and fresh mint palette, warm ivory envelope, strong contrast and restrained professional finish. Centered square 1:1 composition, the icon fills roughly 85% of canvas with safe padding, transparent exterior, rounded forest-green squircle tile behind the envelope. Must be recognizable at 16 and 32 pixels. Single icon only, no presentation sheet, no mockup, no lettering, no words, no watermark, no tiny details, no extra floating decorations. Crisp clean edges. Intended for GitHub README branding and Chrome/Edge extension toolbar.
